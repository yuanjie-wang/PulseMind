PulseMind 安装说明（不需要管理员权限）
======================================

这个文件夹里有：
  install.sh      安装程序（双击它）
  uninstall.sh    卸载程序（以后不想要时双击它）
  PulseMind/      应用本体
  icon.png        图标

安装步骤
--------
1. 先在任意位置把压缩包解压出本文件夹（右键压缩包 → 解压到此处）。
2. 双击 install.sh。
3. 若弹出询问，选择「运行」或「在终端中运行」。
4. 若双击只是打开了文本：关掉文本窗口，右键 install.sh → 属性 →
   勾选「允许作为程序执行」（有的系统写作「允许以程序执行文件」）→
   确定，然后再双击一次。
5. 稍等几秒，PulseMind 会自己打开。以后从「开始菜单」里搜 PulseMind
   就能打开。

它装在哪里
----------
  ~/Applications/PulseMind        应用本体（~ 表示你的家目录）
  ~/.local/share/applications/    菜单入口
  ~/.local/share/icons/           图标

不会往系统目录写任何东西，也不会要管理员密码。

我的数据在哪
------------
  ~/.pulsemind

聊天记录、设置都在这里。卸载不会删除它，重装后还能接着用。

卸载
----
双击 uninstall.sh（双击无效时，同上一步在属性里允许执行）。

只想试用、不装菜单
------------------
进入 PulseMind 文件夹，双击里面的 pulsemind 直接运行即可（同样可能需要
在属性里允许执行）。这样不会创建菜单项。

遇到问题
--------
· 双击后一闪而过或没反应：右键 install.sh → 在终端中运行，看一眼报错。
· 若弹出「PulseMind 安装未完成」的通知：多半是压缩包没解压完整，重新解压后再试。
· 不要把这个文件夹放在 U 盘里运行；解压到电脑上再装。
